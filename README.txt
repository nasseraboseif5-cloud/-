# صدقة جارية

ملفات موقع ويب تقدمي (PWA) باللغة العربية.

## النشر على GitHub Pages
1. ارفع محتويات هذا المجلد مباشرة إلى جذر مستودع GitHub.
2. من Settings > Pages اختر Deploy from a branch ثم main و /(root).
3. افتح رابط Pages عبر HTTPS.

## ملاحظات مهمة
- القرآن يُجلب من AlQuran Cloud عند الاتصال، وتُحفظ السورة التي تفتحها محليًا بعد تحميلها.
- الصوت يعتمد على روابط صوتية خارجية؛ تحقق من عمل كل قارئ قبل الاعتماد النهائي. قد تختلف إتاحة الملفات الصوتية.
- التفسير التفصيلي، تنزيل الصوت للاستماع دون إنترنت، والتنبيهات المجدولة ليست مفعلة في هذه النسخة الأولية، رغم ظهور عناصر تمهيدية لها.
- اتجاه القبلة يتطلب إذن الموقع وبوصلة هاتف معايرة.
- الأذكار والأدعية المعروضة عينة أولية؛ يجب مراجعة النصوص والتخريج قبل التوسع والنشر العام.
